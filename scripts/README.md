# Operations & Management Scripts

This folder is reserved for future automation scripts to launch, inspect, and simulate node failures across the distributed campus system.

**Planned Future Scripts:**
- `start_all_nodes.py`: Launches API Gateway and all department nodes concurrently.
- `simulate_node_failure.py`: Simulates unexpected node termination to test fault tolerance.

*Note: In Phase 1, nodes can be started independently using python or uvicorn commands.*
